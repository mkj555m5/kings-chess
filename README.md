# ♛ شطرنج الملوك — Kings Chess

لعبة شطرنج كاملة بجميع القوانين بتصميم ملكي فاخر، مع **ذكاء اصطناعي حقيقي يلعب ويعلّق بالعربية**، و**لعب أونلاين ضد لاعبين حقيقيين**.

![Tech](https://img.shields.io/badge/Next.js%2016-TypeScript-black) ![Tech](https://img.shields.io/badge/Socket.io-WebSocket-gold) ![Tech](https://img.shields.io/badge/AI-gemma4-amber)

## ✨ المميزات

### ♟️ لعبة الشطرنج
- **جميع قوانين الشطرنج الكاملة**: التبييت، الأخذ بالتجاوز (en passant)، ترقية البيدق، الكش والمات، الطريق المسدود، قاعدة الخمسين نقلة، التكرار ثلاث مرات، قطع غير كافية
- تصميم ملكي فاخر: رقعة جوز وذهب مع إطار متدرج وقطع أنيقة
- سحب وإفلات أو النقر للحركة، إبراز النقلة الأخيرة والنقلات القانونية وتوهج الكش
- مؤثرات صوتية مولّدة برمجياً (نقلة، أكل، كش، فوز، خسارة)
- سجل نقلات، قطع مأكولة مع فرق المواد، شريط تقييم المحرك
- ساعات ملعبة: بدون وقت / ٣ / ٥ / ١٠ دقائق
- تراجع، استسلام، قلب الرقعة (للعب المحلي)
- واجهة عربية كاملة RTL، متوافقة مع الجوال

### 🤖 الوزير (الذكاء الاصطناعي)
- **دمج ذكي**: محرك minimax محلي (تقليم alpha-beta + جداول مواقع القطع + بحث كيشوتية) يولّد أفضل الحركات، والنموذج اللغوي **gemma4** يختار النقلة الاستراتيجية
- **شخصية متفاعلة**: الوزير يعلّق على نقلاته ونقلاتك بالعربية بأسلوب طريف واثق — **وليس في كل مرة**! (احتمالية ذكية تتزايد مع الأكل والكش والأخطاء الكبيرة)
- 3 مستويات: مبتدئ (سهل)، محترف (متوسط)، أسطورة (عمق 3)
- كشف الأخطاء: يعلم متى تخطئ ويسخر لطيفاً، ومتى تُبدع ويمدحك
- تعليقات نهاية المباراة حسب النتيجة

### 🌐 اللعب الأونلاين
- **مباراة سريعة**: مواجهة فورية عبر طابور انتظار حسب الضبط الزمني
- **غرف خاصة**: كود من 5 أحرف تشاركه مع أصدقائك
- خادم موثوق: كل نقلة تُتحقق على الخادم عبر chess.js
- دردشة مباشرة أثناء المباراة، عروض تعادل، مباراة ثأر مع تبديل الألوان
- استعادة الاتصال تلقائياً عند الانقطاع، إشعارات مغادرة الخصم

### 🤖 بوت تلجرام (جديد!)
- **تسجيل دخول تلقائي**: من يدخل الموقع عبر رابط البوت يُفتح الموقع مسجلاً باسمه فوراً — بدون كلمة مرور أو كتابة اسم
- **تحديات بأمر واحد**: `/challenge` ينشئ تحدياً ويعطيك رابطاً مباشراً للمشاركة، و`/challenge @user 3` يتحدى مستخدماً معيناً بوقت محدد
- **إشعارات حية**: قبول التحدي، بدء المباراة، النتيجة النهائية — كلها تصلك في تلجرام
- **الأوامر ظاهرة بالكامل**: قائمة أوامر كاملة في `/help` وقائمة زر القائمة في تلجرام
- **لوحة مالك كاملة**: `/panel` — إحصائيات شاملة، الغرف النشطة، المستخدمون، آخر المباريات، بث إذاعي لكل المستخدمين
- إحصائيات شخصية `/stats` ولوحة متصدرين `/top` داخل البوت

### 📊 الإحصائيات
- عدّاد مرات الفوز/الخسارة/التعادل + نسبة الفوز + سلسلة الانتصارات (محفوظة محلياً)
- سجل آخر 25 مباراة
- **لوحة متصدرين عالمية** لأفضل لاعبي الأونلاين (قاعدة بيانات SQLite)

## 🚀 التشغيل المحلي

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) إعداد متغيرات البيئة
cp .env.example .env
# ثم عدّل .env وضع مفتاح OLLAMA_API_KEY الخاص بك من ollama.com

# 3) قاعدة البيانات
npm run db:push

# 4) التطوير (واجهة على 3000 + خادم اللعب على 3003)
npm run dev
bun run dev   # داخل mini-services/chess-server لخادم الأونلاين

# إنتاج
npm run build
npm start
```

## ☁️ النشر على Cloudflare Workers (موصى به — مجاني)

التطبيق جاهز بالكامل لـ Cloudflare: الواجهة عبر **OpenNext**، اللعب الأونلاين عبر **Durable Objects + SSE**، والإحصائيات العالمية عبر **D1**. المحرك الحسابي يعمل في متصفح اللاعب ليبقى الاستهلاك ضمن حدود الخطة المجانية.

### الخطوات

```bash
# 0) تسجيل الدخول (مرة واحدة)
npx wrangler login

# 1) إنشاء قاعدة بيانات D1 وتطبيق المخطط (للإحصائيات العالمية)
npm run cf:db:init
# ثم انسخ database_id من المخرجات وضعه في wrangler.jsonc

# 2) نشر خدمة الوقت الحقيقي (الغرف + المباراة السريعة)
npm run cf:deploy:rt
# ستجد رابط الخدمة في المخرجات مثل:
# https://kings-chess-rt.<حسابك>.workers.dev

# 3) ضع الرابط في wrangler.jsonc → vars.REALTIME_URL ثم انشر التطبيق
npm run cf:deploy:app

# 4) مفتاح Ollama (سر - لا يوضع في الملفات)
npx wrangler secret put OLLAMA_API_KEY
```

> **إن كان لديك نطاق مخصص على Cloudflare**: يمكنك استخدام رابط نسبي بدلاً من workers.dev — أضف route لنمط `<نطاقك>/rt/*` في `cloudflare/realtime/wrangler.jsonc` واترك `REALTIME_URL` فارغة (الافتراضي `/rt`).

### متغيرات بيئة Cloudflare
| المتغير | القيمة | ملاحظات |
|---------|--------|---------|
| `OLLAMA_API_KEY` | مفتاحك من ollama.com | **سر** — يضاف بـ `wrangler secret put` |
| `AI_MODEL` | `gemma4` | مضبوط في wrangler.jsonc (افتراضي) |
| `OLLAMA_BASE_URL` | `https://ollama.com` | مضبوط (افتراضي) |
| `REALTIME_URL` | رابط خدمة kings-chess-rt | من خطوة 2 أعلاه |
| `CF_DEPLOY` | `1` | مضبوط تلقائياً في wrangler.jsonc |

### ملاحظات
- معاينة محلية للحزمة: `npm run cf:preview`
- أرخص تشغيل للذكاء الاصطناعي: محرك التحليل يعمل في متصفح اللاعب، والخادم يستدعي gemma4 فقط
- الإحصائيات العالمية تحتاج قاعدة D1 (خطوة 1) — بدونها تعمل اللعبة كاملة والإحصائيات تظهر صفرية

## 🚂 النشر على Railway (يشتمل بوت تلجرام)

التطبيق جاهز لـ Railway (خادم واحد يخدم الواجهة + socket.io + بوت تلجرام معاً):

1. ارفع الكود إلى GitHub (المستودع جاهز بالأسفل)
2. على [Railway](https://railway.app): **New Project → Deploy from GitHub repo** واختر المستودع
3. أضف متغيرات البيئة (Variables):
   | المتغير | القيمة | ملاحظات |
   |---------|--------|---------|
   | `OLLAMA_API_KEY` | مفتاحك من [ollama.com](https://ollama.com) | إلزامي للعب ضد الوزير وتعليقاته |
   | `OLLAMA_BASE_URL` | `https://ollama.com` | اختياري (هو الافتراضي — غيّره فقط لو تستضيف Ollama محلياً) |
   | `AI_MODEL` | `gemma4` | اختياري (هو الافتراضي) |
   | `DATABASE_URL` | `file:/app/db/custom.db` | اختياري — يُضبط تلقائياً أثناء البناء/التشغيل إن لم تضع شيئاً |
   | `TELEGRAM_BOT_TOKEN` | رمز البوت من [@BotFather](https://t.me/BotFather) | لتفعيل بوت تلجرام |
   | `TELEGRAM_OWNER_ID` | معرّفك الرقمي (من `/myid` في البوت) | يفعّل لوحة المالك `/panel` — عدة معرفات بفواصل |
   | `SITE_URL` | رابط موقعك على Railway | اختياري — يُكتشف تلقائياً من `RAILWAY_PUBLIC_DOMAIN` |
4. البناء والتشغيل **آليّان بالكامل** عبر ملفي `nixpacks.toml` + `railway.json`:
   - يُثبَّت **Node.js 22 LTS** صراحةً (دعم Node 18 انتهى وأُزيل من nixpkgs — بدون هذا التثبيت يفشل البناء بخطأ "Node.js 18.x has reached End-Of-Life")
   - البناء: `prisma generate` ← `prisma db push` ← `next build`
   - التشغيل: `prisma db push` ← `server.mjs` (Next + socket.io + بوت تلجرام)
5. Generate Domain وافتح رابطك! 🎉

### 🤖 إعداد بوت تلجرام (خطوة بخطوة)

1. افتح [@BotFather](https://t.me/BotFather) في تلجرام → أرسل `/newbot` → اختر اسماً ومعرّفاً → انسخ **الرمز**
2. ضع الرمز في متغير `TELEGRAM_BOT_TOKEN` على Railway وأعد النشر
3. افتح بوتك وأرسل `/start` — ستظهر لك القائمة الكاملة والأزرار
4. أرسل `/myid` وانسخ معرّفك إلى `TELEGRAM_OWNER_ID` لتفعيل لوحة المالك
5. جرّب: `/login` لرابط دخول تلقائي، `/challenge` لإنشاء تحدي، `/panel` للوحة المالك

> ✅ **Webhook تلقائي**: عند الإقلاع يفعّل البوت Webhook بنفسه على `https://<نطاقك>/telegram-webhook/<رمز-مستخرج-من-التوكن>` — بلا أي إعداد يدوي.

> 💡 **للتشغيل المحلي بدون رابط عام**: ضع `TELEGRAM_POLLING=1` في `.env` وسيعمل البوت بوضع Polling.

> 💡 **ملاحظة**: نظام الملفات على Railway مؤقت — إحصائيات المنصة العالمية تُعاد للتصفير عند إعادة النشر. للحفظ الدائم أضف **Volume** موصولاً بمسار `/app/db` (نفس المسار الافتراضي لـ `DATABASE_URL`). الإحصائيات الشخصية محفوظة في متصفح اللاعب ولا تتأثر.

> 🤖 يكتشف التطبيق بيئة Railway تلقائياً (عبر `RAILWAY_ENVIRONMENT`) ويضبط اتصال socket.io على نفس النطاق بمسار `/socket.io` — بلا أي إعداد إضافي.

### 📜 أوامر بوت تلجرام (القائمة الكاملة)

| الأمر | الوظيفة |
|-------|---------|
| `/start` | القائمة الرئيسية + رابط دخول تلقائي |
| `/login` | 🔑 رابط دخول فوري للموقع (تسجيل دخول تلقائي) |
| `/challenge` | ⚔️ إنشاء تحدي + رابط مشاركة |

| `/top` | 🏆 لوحة المتصدرين |

| `/panel` | 👑 لوحة المالك (أزرار تفاعلية) |
