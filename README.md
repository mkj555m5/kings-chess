# ♛ شطرنج الملوك — Kings Chess

لعبة شطرنج كاملة بجميع القوانين بتصميم ملكي فاخر، مع **ذكاء اصطناعي حقيقي يلعب ويعلّق بالعربية**، و**لعب أونلاين ضد لاعبين حقيقيين**.

![Tech](https://img.shields.io/badge/Next.js%2016-TypeScript-black) ![Tech](https://img.shields.io/badge/Socket.io-WebSocket-gold) ![Tech](https://img.shields.io/badge/AI-gemma4-amber)

## ✨ المميزات

### ♟️ لعبة الشطرنج
- **جميع قوانين الشطرنج الكاملة**: التبييت، الأخذ بالتجاوز (en passant)، ترقية البيدق، الكش والمات، الطريق المسدود، قاعدة الخمسين نقلة، التكرار ثلاث مرات، قطع غير كافية
- تصميم ملكي فاخر: رقعة جوز وذهب مع إطار متدرج وقطع أنيقة
- سحب وإفلات أو النقر للحركة، إبراز النقلة الأخيرة والنقلات القانونية وتوهج الكش
- مؤثرات صوتية مولّدة برمجياً (نقلة، أكل، كش، فوز، خسارة)
- سجل نقلات، قطع مأكولة مع فرق المواد، شريط تقييم المحرك
- ساعات ملعبة: بدون وقت / ٣ / ٥ / ١٠ دقائق
- تراجع، استسلام، قلب الرقعة (للعب المحلي)
- واجهة عربية كاملة RTL، متوافقة مع الجوال

### 🤖 الوزير (الذكاء الاصطناعي)
- **دمج ذكي**: محرك minimax محلي (تقليم alpha-beta + جداول مواقع القطع + بحث كيشوتية) يولّد أفضل الحركات، والنموذج اللغوي **gemma4** يختار النقلة الاستراتيجية
- **شخصية متفاعلة**: الوزير يعلّق على نقلاته ونقلاتك بالعربية بأسلوب طريف واثق — **وليس في كل مرة**! (احتمالية ذكية تتزايد مع الأكل والكش والأخطاء الكبيرة)
- 3 مستويات: مبتدئ (سهل)، محترف (متوسط)، أسطورة (عمق 3)
- كشف الأخطاء: يعلم متى تخطئ ويسخر لطيفاً، ومتى تُبدع ويمدحك
- تعليقات نهاية المباراة حسب النتيجة

### 🌐 اللعب الأونلاين
- **مباراة سريعة**: مواجهة فورية عبر طابور انتظار حسب الضبط الزمني
- **غرف خاصة**: كود من 5 أحرف تشاركه مع أصدقائك
- خادم موثوق: كل نقلة تُتحقق على الخادم عبر chess.js
- دردشة مباشرة أثناء المباراة، عروض تعادل، مباراة ثأر مع تبديل الألوان
- استعادة الاتصال تلقائياً عند الانقطاع، إشعارات مغادرة الخصم

### 📊 الإحصائيات
- عدّاد مرات الفوز/الخسارة/التعادل + نسبة الفوز + سلسلة الانتصارات (محفوظة محلياً)
- سجل آخر 25 مباراة
- **لوحة متصدرين عالمية** لأفضل لاعبي الأونلاين (قاعدة بيانات SQLite)

## 🚀 التشغيل المحلي

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) إعداد متغيرات البيئة
cp .env.example .env
# ثم عدّل .env وضع مفتاح OLLAMA_API_KEY الخاص بك من ollama.com

# 3) قاعدة البيانات
npm run db:push

# 4) التطوير (واجهة على 3000 + خادم اللعب على 3003)
npm run dev
bun run dev   # داخل mini-services/chess-server لخادم الأونلاين

# إنتاج
npm run build
npm start
```

## ☁️ النشر على Railway

التطبيق جاهز لـ Railway بالكامل (خادم واحد يخدم الواجهة + socket.io معاً):

1. ارفع الكود إلى GitHub (المستودع جاهز بالأسفل)
2. على [Railway](https://railway.app): **New Project → Deploy from GitHub repo** واختر المستودع
3. أضف متغيرات البيئة (Variables):
   | المتغير | القيمة | ملاحظات |
   |---------|--------|---------|
   | `OLLAMA_API_KEY` | مفتاحك من [ollama.com](https://ollama.com) | إلزامي للعب ضد الوزير وتعليقاته |
   | `OLLAMA_BASE_URL` | `https://ollama.com` | اختياري (هو الافتراضي — غيّره فقط لو تستضيف Ollama محلياً) |
   | `AI_MODEL` | `gemma4` | اختياري (هو الافتراضي) |
   | `DATABASE_URL` | `file:./db/custom.db` | اختياري (هو الافتراضي) |
4. Railway سيكتشف Nixpacks تلقائياً ويشغّل `npm run build` ثم `npm start`
5. Generate Domain وافتح رابطك! 🎉

> 💡 **ملاحظة**: نظام الملفات على Railway مؤقت — إحصائيات المنصة العالمية تُعاد للتصفير عند إعادة النشر. للحفظ الدائم أضف Volume موصولاً بمسار `/app/db`. الإحصائيات الشخصية محفوظة في متصفح اللاعب ولا تتأثر.

> 🤖 يكتشف التطبيق بيئة Railway تلقائياً (عبر `RAILWAY_ENVIRONMENT`) ويضبط اتصال socket.io على نفس النطاق بمسار `/socket.io` — بلا أي إعداد إضافي.

## 🧱 البنية التقنية

```
├── src/
│   ├── app/
│   │   ├── page.tsx               # الصفحة الرئيسية (إدارة المشاهد)
│   │   ├── layout.tsx             # RTL + خط Cairo
│   │   └── api/
│   │       ├── ai/move/           # نقلة الوزير (محرك + LLM)
│   │       ├── ai/comment/        # تعليقات الوزير الاحتمالية
│   │       ├── stats/             # الإحصائيات العالمية
│   │       └── config/            # إعدادات socket للبيئة
│   ├── components/chess/          # الرقعة، القطع، الشاشات، الحوارات
│   └── lib/
│       ├── chess-engine.ts        # minimax + alpha-beta + PST
│       ├── ai-brain.ts            # دماغ الوزير (LLM + بدائل)
│       └── ...                    # أصوات، إحصائيات، أدوات
├── multiplayer/
│   └── game-core.mjs              # نواة الخادم الموثوق (غرف + تحقق + ساعات)
├── mini-services/chess-server/    # خدمة الأونلاين للتطوير (منفذ 3003)
├── server.mjs                     # خادم الإنتاج الموحد (Next + socket.io)
└── prisma/schema.prisma           # سجل المباريات
```

**التقنيات**: Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · chess.js · socket.io · Prisma + SQLite · Ollama API (نموذج gemma4) · Framer Motion · Web Audio API
